# DirectionsTablet

Dashboard at tablet width (834px portrait, the top 1000px of the 1194px frame) in all four directions: light row, then dark row.

The tablet layout: collapsed 72px icon sidebar (Dashboard, Activity, Envelopes, Insights) with a Profile item at the bottom, topbar with "+ Add", summary and health score side by side, cash flow beside the envelope split, the spending chart, then recent entries. Landscape (1194 × 834) uses the desktop arrangement with a 3-column grid.
