# Badge

shadcn Badge for three facts only: "Voided" on entries, "Archived" on envelopes, and the send status in Reports.

- Default: `muted` fill, `border` outline, 12px medium text in `muted-foreground`. Status "Accepted by email provider" uses `foreground` text; "Failed" uses `destructive` text and border with a 10% tint.
- Never the word "delivered". Accepted by the provider is not delivery.
