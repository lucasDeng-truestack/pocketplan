# Directions

The four theme directions from the brief, side by side, each as the top of the Dashboard and the open Quick add sheet in light and dark. Every pane is the same markup: only the theme id on its wrapper differs, so a direction is a set of token values plus the radius and font overrides in `bundle.css`.

Use this card to compare directions. The recommendation and the reasoning are in the Directions section of the brand book.

- Modern (recommended): the current build, stone neutrals, Geist, 8px base radius.
- Retro: cream paper, brown ink, gold rules, Fraunces headings, IBM Plex Mono amounts, ruled card rows, fine grain.
- Pixel: square corners, 2px hard borders, stepped shadows, Press Start 2P for headings and large amounts only, dotted dividers.
- Premium: ivory and near-black, Instrument Serif amounts, a thin metallic rule across the top of each card, no shadows.
