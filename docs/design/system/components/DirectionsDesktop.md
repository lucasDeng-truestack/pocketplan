# DirectionsDesktop

Dashboard at desktop width (1280 × 800) in all four directions, light beside dark. Same markup as the DashboardScreen card; only the theme id on each wrapper differs.

Use it to judge a direction where it is hardest: large areas of chrome, a full sidebar, many amounts side by side. Modern and Premium stay calm at this size; Retro's ruled cards and Pixel's 2px borders are louder across a wide grid, which is part of the recommendation in the Directions section.
