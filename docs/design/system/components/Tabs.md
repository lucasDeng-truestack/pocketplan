# Tabs

shadcn Tabs as the Expense · Income · Transfer switcher in Quick add, the Type filter in Activity, and the Envelopes · Insights · Reports hub.

- The selected tab sits on `card` with `shadow-sm`; the track is `muted`. The highlight slides between tabs with a Framer Motion shared layout animation (200ms, ease-out); reduced motion swaps instantly.
- Arrow keys move between tabs when a tab has focus. No number-key shortcuts: the amount field has focus and digits must type.
- Minimum 40px tall inside a 48px track.
